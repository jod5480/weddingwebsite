# 💍 Luxury Interactive Wedding Invitation & RSVP Portal

A modern, cinematic digital wedding invitation web application crafted for an unforgettable guest experience. Built with a focus on luxury editorial typography, smooth interactions, and interactive 3D WebGL visuals.

## ✨ Key Highlights

- **Interactive 3D WebGL Rings:** Realistic 18K yellow and rose gold wedding rings that roll across the screen as guests scroll, interlocking seamlessly at the closing blessing.
- **Cinematic Ambient Experience:** Integrated background audio player with sound wave visualizations and gentle falling petal particle effects.
- **Live RSVP System:** Frictionless attendance confirmation with dietary and plus-one preferences backed by a lightweight Hono & SQLite API.
- **Digital Guestbook:** Guests can leave heartfelt messages and blessings displayed in an elegant masonry board.
- **Event Schedule & Interactive Venue Maps:** Multi-day itinerary countdown, dress code guides, and direct Google Maps navigation.
- **Ultra-Smooth Scroll & Micro-Interactions:** Powered by Lenis smooth scrolling, Framer Motion transitions, and responsive mobile-first design.

## 🛠️ Tech Stack

- **Frontend:** React 19, TypeScript, Vite, Tailwind CSS v4, Lucide Icons
- **3D & Visuals:** Three.js (PBR materials & custom environment lighting), Framer Motion, Lenis
- **Backend / API:** Hono, Drizzle ORM, LibSQL / SQLite
- **UI Components:** Radix UI / Shadcn UI primitives, Sonner toasts
